## [📱 Netli.fyi: Netlify from your phone](https://netli.fyi)

<a href="https://netli.fyi"><img src="https://perttu.dev/images/apps/netli-fyi/icon.jpg" width="96" align="right" alt="Netli.fyi app icon"></a>

A native Netlify client for iPhone, iPad and Android. Watch a build stream its logs, redeploy with a swipe, roll back a bad deploy, check traffic, edit DNS records and read form submissions without opening a laptop.

- **Deploys:** live build logs; trigger, retry, cancel, roll back and lock
- **Traffic:** requests by status code, bandwidth, response times and a searchable request log
- **Widgets & Live Activities:** build status on the Home Screen, Lock Screen and in the Dynamic Island
- **Notifications:** a ping when a deploy starts or a form entry arrives, free for every account

Free to use, with an optional subscription for real-time alerts and Live Activities.
